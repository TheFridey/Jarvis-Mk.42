Kernel's correlationId because the id arrives inside a JSON string and its quotes are escaped, so the
regex never matched and AgentRuntime correctly rejected the proposal as forged - after the provider
call had already succeeded. The production half of the defect was the silence: /desktop/cognition
returned {"error":"internal_error"} while logging a bare event with no name, code, message or frame.
A successful inference reported as a failure, with nothing to debug, cost several campaigns.

classification to stderr (component, event, node, errorName, errorCode, message <=300 chars, top
three frames) with no bodies, statements or credentials. scripts/convergence-acceptance.ts is
13/13, exit 0.
